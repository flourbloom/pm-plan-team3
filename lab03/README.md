
# Lab-03 · Life Cycle Selection and Tailoring Decision Record

This Lab-03 project selects a Hybrid approach for the Realtime Quiz project. Hybrid was selected because it achieved the highest weighted score of 4.00, compared with 3.40 for Pure Scrum and 2.60 for Waterfall. It combines predictive planning and formal phase gates with four consecutive two-week Scrum sprints, allowing the team to manage uncertainty while maintaining sponsor control.

The sponsor (Head of IT) controls the project through four formal stage gates: G1 plan approval, G2 MVP checkpoint, G3 feature complete and G4 pilot result and release decision. The Project Manager prepares weekly highlight reports, monitors project tolerances and escalates exceptions to the sponsor. Sprint reviews provide regular feedback, while measurable acceptance criteria ensure that the project remains aligned with the approved plan and the week 14 pilot target.
